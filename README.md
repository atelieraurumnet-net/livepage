#### 解説
　このサイトは一つの仮想マシンであり、歴史を含む本宇宙のエミュレーションである。実像なきインターネット上の宇宙に対して、五感に訴えるアプローチを採った。ロード画面ではマシンへの接続と世の創生を表現し、ライフゲームや音は星星や粒粒を含む全ての生命の有無の変遷を表現している。
